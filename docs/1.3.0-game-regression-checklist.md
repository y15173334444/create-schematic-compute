## A. 安全面 / Security（7）

1. [ ] **多人 BUS_IN 改名同步 + 同名删除门控**（P1-8 / P1-9）——双客户端各建同名 BUS_OUT：
   A 给 BUS_IN 改名 → 双方即时见到新名、各宿主面板不永久挂起；随后 A 删除与 B 同名的 BUS_OUT
   → B 的频道定义、已发布值与连线完好（不得被"空定义"收敛剪线）。
2. [ ] **座位输入骑乘校验（座位劫持）**（座位输入无骑乘校验）——旁观者在 128 格内对他人座位发
   操作 → 被拒；骑乘者本人操作 → 驾驶/按键位正常。
3. [ ] **Sable 扫描钳制**（Sable 扫描信任客户端坐标与半径）——伪造超大半径/越界原点 → 服务端
   钳制到合法范围；正常扫描不受影响。
4. [ ] **op 越界与未知序号**（越界索引无上界 · 未知操作序号直接断连）——越界热栏/帧/控制点提交
   → REJECT 预检拒绝、连接保持；伪造未知 op 序号 → 不断连、收到回执。
5. [ ] **Blob 上限与归属**（Blob 分片无上限且 blobId 跨玩家串包）——超过 64 片或 256 条 → 协议
   错误拒绝；A 取 B 的 blobId → fail-closed。
6. [ ] **撤销/重做恢复曲目与封装**（撤销恢复丢失曲目与封装子图）——撤销再重做后 NBS 曲目与
   封装子图完整回归。
7. [ ] **temp-id 漏斗**（NBS 编辑器 op 出口绕过 temp-id 漏斗 · 编辑会话生命周期缺口 P2-10）——
   新建节点 ACK 未回时输入的参数 → ID 重映射后仍到达服务端；拆方块/关屏后会话无残留。

## B. 封装与求值时序 / Encapsulation & Eval Timing（5）

8. [ ] **封装内时序**（封装子图状态与完成脉冲透传）——封装内跑含脉冲/延时指令的图 →
   「指令永不停止」v2 形态不复现；完成脉冲穿出封装正确触发下游。
9. [ ] **封装音频时间戳**（封装子求值器音频时间戳冻结）——封装内音频节点持续播放不冻结、
   不错拍。
10. [ ] **公式递归防线**（公式递归深度无上限）——自引用/互引用公式 → 不崩服不卡死，按深度
    防线拒绝。
11. [ ] **公式去重缓存排除出错**（公式去重缓存缓存出错结果）——公式出错后改正 → 即时生效，
    不被旧的出错结果粘住。
12. [ ] **PRIVATE_OUT 空名幽灵频道**（PRIVATE_OUT 空名写幽灵频道）——清空 PRIVATE_OUT 名字
    → 不再生成幽灵频道条目。

14. [ ] **齿轮箱/变速器触发器差分**（齿轮箱/变速器触发器状态不同步 P2-13）——控制端改触发器
